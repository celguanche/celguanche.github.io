Proyectos

Proyecto principal

FarmaGest

Aplicación JavaFX con arquitectura en capas (servicios y DAO) que registra cada venta y descuenta el stock por lote en una única transacción JDBC. Si algún producto carece de existencias suficientes, se revierte toda la venta.

  • Java
  • JavaFX
  • JDBC
  • MySQL
  • Transacciones
  • Arquitectura en capas
  • Integridad transaccional en ventas y stock. El descuento de existencias por lote y el registro de la venta se ejecutan dentro de una misma transacción JDBC con rollback automático ante falta de stock o fallo.
  • Separación de responsabilidades. Organización en capas (interfaz JavaFX, servicios de negocio y DAO con MySQL) para mantener la lógica de stock y persistencia desacoplada.
  • Gestión operativa de farmacia. Administración de catálogo, lotes y caducidades, compras a proveedores, ventas, usuarios y auditoría.
Ver FarmaGest en GitHub

Integración de datos

Customer Data Importer

  • Java 21
  • JavaFX
  • JDBC
  • MySQL
  • Apache Commons CSV

Importador CSV que compara clientes por DNI con MySQL, permite elegir qué datos conservar cuando hay diferencias y registra las filas rechazadas con el motivo. Validado mediante pruebas con lotes de 500 registros para asegurar que un error puntual no detenga el procesamiento del archivo.

Ver Customer Data Importer en GitHub
