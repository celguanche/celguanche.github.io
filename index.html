Proyectos

Customer Data Importer

  • Java 21
  • JavaFX
  • JDBC
  • MySQL
  • Apache Commons CSV

Aplicación de escritorio para revisar un archivo de clientes antes de incorporarlo a MySQL. La vista previa separa los clientes nuevos, los existentes y las filas que necesitan corrección.

  • Comprueba la letra de control del DNI, el código postal y el formato del correo. También detecta DNI repetidos en el archivo.
  • Permite comparar los datos del CSV con los de MySQL y elegir qué clientes actualizar. Si un campo opcional llega vacío, conserva su valor anterior.
  • Registra los rechazos con fecha, número de línea y motivo. Las filas rechazadas se pueden exportar, corregir y volver a cargar.

Probé el lector con 500 clientes ficticios de seis campos y mantuve la compatibilidad con los CSV originales de tres columnas.

Ver Customer Data Importer en GitHub

FarmaGest

  • Java
  • JavaFX
  • JDBC
  • MySQL

Aplicación de escritorio para gestionar las operaciones de una farmacia y seguir cómo afectan las compras y las ventas al inventario.

  • Reúne la gestión de productos, proveedores y empleados en una interfaz de JavaFX.
  • Permite añadir varios productos con sus cantidades a un mismo pedido de compra o a una venta.
  • Registra las entradas y salidas de existencias y guarda las operaciones en MySQL mediante JDBC.
Ver FarmaGest en GitHub
