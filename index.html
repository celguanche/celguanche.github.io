Proyecto principal

FarmaGest

Una aplicación de escritorio para gestionar una farmacia y seguir cómo cambia el stock de cada producto con las compras y las ventas.

  • Java
  • JavaFX
  • JDBC
  • MySQL

Al registrar una venta, el usuario elige un producto, indica la cantidad y puede añadir otra línea antes de confirmar la operación. El mismo flujo permite preparar pedidos de compra con varios productos. La interfaz está desarrollada en JavaFX y las operaciones se guardan en MySQL mediante JDBC.

  • Compras y proveedores. Gestión de proveedores y registro de pedidos con sus productos y cantidades.
  • Ventas e inventario. Registro de ventas y seguimiento de las entradas y salidas de existencias.
  • Gestión de la farmacia. Administración del catálogo de productos y de los empleados desde la aplicación.
Ver FarmaGest en GitHub

Customer Data Importer

  • Java 21
  • JavaFX
  • JDBC
  • MySQL
  • Apache Commons CSV

Herramienta para revisar archivos CSV antes de importar clientes a MySQL. Detecta errores y DNI duplicados, permite comparar los registros existentes y exporta las filas rechazadas para corregirlas. Probé el lector con 500 clientes ficticios de seis campos.
